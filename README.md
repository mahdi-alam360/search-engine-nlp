# Search Engine — NLP & Retrieval

Python project by Mahdi Alam · October–November 2022.

> **Repository status:** Documentation only. The original source code, corpus, preprocessing configuration, evaluation queries, and results are not included. This repository summarizes the work described in Mahdi's resume.

## Overview

A search engine project exploring document retrieval and classification baselines. The work implemented **TF–IDF** and **BM25** retrieval, trained **Naïve Bayes** and **linear SVM** baselines, and compared retrieval effectiveness across models.

## Methods

| Method | Role in the project |
| --- | --- |
| TF–IDF | Term-weighted document representation and retrieval |
| BM25 | Document ranking |
| Naïve Bayes | Classification baseline |
| Linear SVM | Classification baseline |

Retrieval and classification are separate tasks; this documentation does not imply that classifier outputs used the same evaluation protocol as ranked search results.

## Engineering focus

- Implementing text retrieval in Python
- Comparing multiple model families
- Evaluating effectiveness rather than assuming one approach is superior
